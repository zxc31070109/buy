# 🇭🇰 香港陀螺連線代購助手 (HK Beyblade Buy App)

針對 iPhone 15 Pro 手機優化的現場高速錄單與金流管理助手，支援一鍵發送 LINE 回覆單與 Google 試算表同步。

---

## 🚀 快速使用指南

### 1️⃣ 本地開發與預覽 (`一鍵啟動.bat`)
- 雙擊執行 **`一鍵啟動.bat`**
- 系統將自動安裝套件並啟動開發伺服器 (`http://localhost:3000`)。

---

## 📦 GitHub Pages 部署設定

當您第一次上傳到 GitHub 時，請依照以下步驟設定 GitHub Pages：

1. 雙擊執行 **`推送到GitHub.bat`**（將代碼推送到您的 GitHub 儲存庫）。
2. 開啟您的 GitHub 專案頁面：`https://github.com/<您的帳號>/buy`
3. 點選 **Settings** -> 左側選單選擇 **Pages**。
4. 在 **Build and deployment** 下方的 **Source**，選擇 **Deploy from a branch**。
5. Branch 選擇 **`main`**，資料夾選擇 **`/ (root)`**，點選 **Save**。
6. 約 1~2 分鐘後，即可透過專案網址開啟網頁！

---

## 🔄 一鍵上傳更新 (`推送到GitHub.bat`)

未來只要修改了程式碼，直接雙擊執行 **`推送到GitHub.bat`** 或 **`push.bat`**，即可自動提交並更新至 GitHub Pages！
